# 🏥 Totem de Atendimento Inteligente & Triagem Digital (SUS)

Um sistema de autoatendimento e triagem hospitalar voltado para o atendimento humanizado, ágil e acessível de pacientes idosos no Sistema Único de Saúde (SUS). O projeto utiliza o **Protocolo de Manchester** para automação da classificação de risco e priorização de atendimento.

---

## 📌 Sobre o Projeto

O objetivo principal do **Totem de Atendimento** é reduzir filas em recepções hospitalares, simplificar a coleta inicial de dados e orientar o paciente de forma clara, intuitiva e autônoma.

A interface foi projetada levando em consideração as necessidades específicas do público idoso, garantindo máxima usabilidade e acessibilidade visual e cognitiva.

---

## ✨ Funcionalidades e Diferenciais

- ♿ **Acessibilidade para Idosos:** Botões ampliados, tipografia de alta legibilidade, modo de alto contraste e navegação simplificada.  
- 🗺️ **Mapa Anatômico de Dor:** Interface visual e interativa para localização intuitiva de sintomas e dores no corpo.  
- 🚦 **Classificação de Risco (Manchester):** Categorização automática por cores (Emergência, Muito Urgente, Urgente, Pouco Urgente, Não Urgente).  
- 🏷️ **Identificação Visual SUS:** Identidade visual alinhada aos padrões do Sistema Único de Saúde.  
- ⚡ **Integração & Automação:** Estrutura pronta para envio de dados e relatórios via automações (Make.com / Gemini AI).

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript (ES6+)  
- **Estilização & UI:** Tailwind CSS  
- **Iconografia:** Lucide Icons  
- **Automação & Processamento:** Make.com & IA Generativa (Google Gemini)
